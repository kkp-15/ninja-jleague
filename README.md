# J1残留ライン早見表

明治安田J1リーグ（2026-27）の残留ライン・降格確率を、Jリーグ公式データから毎日自動計算します。

https://jleague.kkpwebninja.com/

## 仕組み

| スクリプト | 役割 |
|---|---|
| `scripts/fetch.py` | 公式データサイトから全380試合を取得し `data/j1.json` に保存 |
| `scripts/analyze.py` | 残り試合を20,000回シミュレーションし、残留ライン・降格確率を計算 |
| `scripts/build.py` | `data/j1.json` から `index.html` を生成 |

毎朝 JST 6:30 に GitHub Actions が3つを順に実行し、変更があれば自動コミット→デプロイします。

## 数字の根拠

- 引分率 25.5% は2025年J1の全380試合の実測値
- 残留ラインの妥当性は過去実績で検証済み（2025年43点／2024年41点。モデルの中央値と一致）
- よく見る「残留ラインは勝点36」は18クラブ時代の数字。20クラブ・38節では41〜43点

非公式のファンサイトです。正確な情報はJリーグ公式サイトをご確認ください。
